**1. 절차적 프로그래밍 (POP)**
* 함수와 절차 중심으로 순차 실행하는 방식
* 실행 속도가 빠르고 직관적이나, 코드가 커지면 유지보수 어려움 (예: C, Pascal)

**2. 객체 지향 프로그래밍 (OOP)**
* 데이터(속성)와 기능(메서드)을 묶은 '객체' 단위들의 상호작용으로 구성하는 방식
* 캡슐화·상속·추상화로 재사용성과 유지보수성이 높아 대규모 프로젝트에 적합 (예: Python, Java, C++)

**3. 클래스 vs 객체 vs 인스턴스**
* **클래스:** 객체를 만드는 설계도 (소나타 설계도)
* **객체:** 설계도로 구현한 실체 (실제 소나타 차량)
* **인스턴스:** 클래스로 생성되어 메모리에 실제로 존재하는 객체 (A씨의 특정 소나타)

**4. 파이썬 모듈화**
* 코드를 기능별 독립 단위(모듈)로 쪼개 관리하는 방법
* 여러 곳에서 불러와(import) 재사용할 수 있어 유지보수와 협업에 유리
